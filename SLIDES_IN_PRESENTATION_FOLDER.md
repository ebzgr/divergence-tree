# Slide presentation location

The HTML slide deck for this project lives in the **`presentation/`** directory at the repository root (next to `src/`, `pyproject.toml`, etc.).

- Main entry: `presentation/index.html`
- See `presentation/README.md` for how to run a local server and regenerate `static/simulations.json`.

If you do not see `presentation/` in the file tree, confirm you opened the **repository root** folder in your editor, not a subfolder.
